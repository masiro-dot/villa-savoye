# Villa Savoye — 建築を歩く

Three.js r180による、プレゼンテーション用のパラメトリック建築模型、revision 3。単位はmです。ビルドや外部CDNは不要で、ライブラリ・テクスチャ・環境マップをすべてローカルで用意しています。地上階と屋上の再調査、修正内容、推定箇所は [MODEL_AUDIT.md](MODEL_AUDIT.md)、輪郭は [plan-audit.svg](plan-audit.svg) を参照してください。

## 起動とGitHub Pages

このフォルダをHTTPサーバーで配信してください。ES Modulesを使うため、index.htmlをダブルクリックする `file://` 起動は対応しません。

Node.jsがある場合： `node serve.mjs` → http://localhost:4173

GitHub Pagesでは、このフォルダ内のファイルをリポジトリのルート（または公開対象のdocsフォルダ）へ配置し、Settings → Pagesで対象ブランチ・フォルダを選択します。相対URLのみを使用しているため、プロジェクトのサブパスにも対応します。公開・リポジトリ作成は行っていません。

## 編集

- `building.js`：DIMENSIONSに外形、階高、柱径、基準グリッド、窓、スロープ、曲面制御点を集約。PLANに屋上・庭園の輪郭、明示的な柱位置、間仕切りを定義。部位別Groupで管理し、静的形状は材質ごとに結合。
- `materials.js`：MATERIAL_CONFIGに主要質感。128px微細ノイズ、256px舗装・芝、128px舗装normal、512×256pxの手続き型環境テクスチャ。PMREMは初期化時の一回のみ。
- `app.js`：OrbitControls、プリセット、表示切替、光、品質切替、レスポンシブ、オンデマンド描画。
- `style.css` / `index.html`：日本語UI、スマートフォン対応、キーボードフォーカス、資料解説。
- `vendor/`：Three.js r180 / OrbitControls / BufferGeometryUtils。MITライセンスは `vendor/LICENSE`。

幅・奥行きを変更すると割合に基づく室配置も追従します。ただし任意の極端な変更を保証する拘束ソルバーではありません。グリッド、階高、開口高さ、曲率などを変えるときは干渉と傾斜を確認してください。

## 操作

マウス左ドラッグで回転、ホイールで拡大、右ドラッグで移動。スマートフォンは一本指で回転、二本指でピンチ・移動。外観／正面／側面／屋上／平面／ピロティ／屋上詳細の7ビュー、屋根・外壁・ガラス・参考家具の切替、自動回転、日射イメージ、全画面を用意。「内部を見る」は屋根・外壁・ガラスを隠し、平面へ移動します。戻すと元の表示設定を復元します。「中庭の建具を見る」で居間の大きなガラス引き戸を近くから確認できます。

## 再現範囲と推定

実測・施工用モデルではありません。公式の非寸法平面図を参照し、主要な空間の位置関係を再構成しました。地下、設備、微細な建具、正確な施工ディテールは省略。曲面ホール、サービス室・ガレージ、居住階の居間／厨房／寝室群、屋外庭園、折り返しスロープ、螺旋階段、屋上ソラリウムを簡略表現しています。間仕切りの戸口・全開口の精密復元は行っていません。

外形19×21.5m、基準グリッド4.75mは名目値を採用し、一次実測図未確認のため**暫定値**としています。階高3.30／3.35m、柱径0.27m、窓腰高1.10m・高さ1.15m、壁厚0.18m、床厚0.22m、スロープ各レーン約1.22m、屋上曲面・ソラリウム高さ、個々の柱・部屋・開口位置はすべて**推定**。DIMENSIONSとPLANのコメントで区別しています。外構・家具は参考配置、方位は概念表示、スライダーは実際の日射計算ではありません。

参照資料：

1. [CMN 公式訪問ガイド 2021（p.2に3層の平面図）](https://www.villa-savoye.fr/content/download/9824393/file/document-visite-villa-savoye-FR-2021.pdf?inLanguage=fre-FR&version=3)
2. [Fondation Le Corbusier — Villa Savoye](https://www.fondationlecorbusier.fr/oeuvre-architecture/realisations-villa-savoye-et-loge-du-jardinier-poissy-france-1928-1931/)
3. [CMN — 新しい建築の五つの原則](https://www.villa-savoye.fr/en/discover/le-corbusier-s-5-points-of-modern-architecture)

資料の図面画像そのものは配布物に含めていません。

## 描画設計

ACESToneMapping、半球光＋方向光一灯、PCF影。ガラスはMeshPhysicalMaterialの透明・環境反射で表現し、屈折用の追加レンダーパスは使いません。金属の反射も同じ事前生成環境マップ。リアルタイム反射・Bloom・ポストプロセスなし。柱・階段・樹木はInstancedMesh、壁などは部位・材質単位でバッチ化。静止時はRAFを停止し、タブ非表示中も停止。操作後は減衰が収束する短時間だけ描画。

自動品質はスマートフォン相当でDPR最大1.25／影1024、PCはDPR最大1.75／影2048。「軽量」「高品質」で手動変更できます。実機の速度はGPU・ブラウザに依存します。

「中庭のスロープを見る」ボタンで、添付写真と比較しやすい広角ビューに移動できます。スロープガラスの水平桟寸法はDIMENSIONS.ramp、屋上の白い表示はMATERIAL_CONFIG.plasterで調整できます。

追加写真に対応して中央ガラスと回り階段を再構築。「スロープから中庭を見る」「螺旋階段を見る」で比較できます。階段はDIMENSIONS.stairで段数・幅・白い側壁・黒い手すりを調整できます。stairsグループは階段本体、railsグループは手すりを管理します。

「1階の玄関を見る」で、曲面ガラス・奥まった両開き扉・袖ガラス・欄間の構成を確認できます。寸法の推定値は building.js の DIMENSIONS.entrance にまとめています。


「1階の背面を見る」でサービス室の白い窓下壁、緑の壁、横桟付き大窓と小窓、端部の扉を確認できます。推定寸法は DIMENSIONS.serviceFacade で管理しています。


「1階の緑の側壁を見る」で2種類の小窓を近くから確認できます。
